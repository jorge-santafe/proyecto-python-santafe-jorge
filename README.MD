# Sistema de Gestión Clínica ACME
## Descripción del proyecto

Este proyecto consiste en el desarrollo de una aplicación de consola en Python para la clínica ACME, cuyo objetivo es sistematizar el registro de pacientes, la gestión de usuarios y el proceso de diagnósticos médicos.

La aplicación permite almacenar y consultar información mediante archivos JSON, facilitando el seguimiento de las consultas médicas y la administración de los datos de los pacientes.

El sistema está desarrollado mediante una arquitectura modular, donde cada archivo Python cumple una función específica

### Funcionalidades
- **Inicio de sesión**: autenticación de usuarios mediante correo electrónico y contraseña.

- **Gestión de usuarios**: registro de personal médico y administrativo.

- **Registro de pacientes**: almacenamiento de información personal de los pacientes.

- **Diagnósticos médicos**: registro de síntomas, diagnósticos y prescripciones médicas.

- **Historia clínica**: consulta del historial médico de cada paciente, incluyendo sus diagnósticos y tratamientos.

- **Control de acceso**: acceso a determinadas funcionalidades según el rol del usuario.

- **Persistencia de datos**: almacenamiento de información en formato JSON.
